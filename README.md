# RangeenLeed Wallpaper Website

A static, responsive wallpaper gallery that showcases high-resolution images and popular wallpaper categories.

## Overview

RangeenLeed is a front-end website for discovering wallpapers inspired by nature, travel, cars, animals, seasons, and abstract designs. The page includes a fixed header, category shortcuts, a masonry-style four-column image gallery, popular category cards, and a detailed footer.

## Features

- Responsive wallpaper gallery with four image columns
- Fixed navigation header and searchable photo input
- Scrollable wallpaper category shortcuts
- Popular image categories with visual cards
- Pexels search links for additional wallpapers
- Responsive mobile layout
- Font Awesome social and interface icons

## Technologies

- HTML5
- CSS3
- Font Awesome 7
- Pexels image and search links

No JavaScript framework or build tool is used.

## Run Locally

1. Clone or download this repository.
2. Open the project folder in your preferred code editor.
3. Open `Main_Project.html` in a web browser.

For the best local experience, you can also use the Live Server extension in VS Code:

1. Install Live Server.
2. Right-click `Main_Project.html`.
3. Select **Open with Live Server**.

## Pages and Links

- `Main_Project.html` is the main entry page.
- The navigation and footer currently include placeholder links for About, Sign-in, contact, policy, and other pages. Those pages are not included unless separate HTML files are added.
- Category links open related searches on Pexels.
